## 正式发布前仍须完成

1. 所有者确定自有代码与三个 Skill 的发行许可，落地根目录 LICENSE 和相应声明。模型条款单独适用。
2. 在指定的新 AutoDL GPU 实例进行从零安装、节点及 4K VFX smoke、经授权的最小 H3 生成、下载、恢复和关机验收。记录实际支出，不以本地测试替代 GPU 证据。
3. 确认介绍视频的视觉质量。视频由本地代码制作，不是模型生成样例；旧 Canvas 首版已被否定，不能用于发布。
4. 确定公开仓库目标、默认分支和发布操作后，替换 README 的 PUBLIC_REPOSITORY_URL 占位符，推送干净历史、运行远端 CI，再创建正式标签与 Release。不要直接把含旧历史的私有仓库切为公开。

目前没有新建或修改 GitHub 仓库、推送、创建标签/Release，未访问生产 GPU 或调用付费生成。云端安装修改尚未完成实机验收，因此不能声明“开源前已全部验证无问题”。
