镜头衔接修订版经项目维护者审阅后，成为仓库首页介绍视频。本记录保存该版的分析与修正方法，供后续迭代参考。

## 1. 真正改变的是分析单位

上一轮已经做了连续逐帧观察，研究了文字的宽高变化、急速位移、缓慢收尾以及金属反射，不能将其描述为“完全没有看动画”。它解决了单个段落内部的问题，却把许多段落当成独立场景处理：上一段结束，下一段从自己的初始状态重新开始。

这次把分析单位扩大为“前镜最后可读的状态 → 交接过程 → 后镜最先成立的状态”。额外追踪六件事：

1. 哪个文字、产品或边界继续存在？
2. 观众刚才看哪里，下一刻还应看哪里？
3. 主体占画面的大小、明暗面积如何变化？
4. 运动方向和速度如何接续，哪里是有意的断点？
5. 下一镜增加了什么信息，是否接住前一镜表达的意思？
6. 声音的重音落在动作发生、占位完成还是阅读停留上？

分析仍依靠连续帧、时间点、播放检查和运动推断，并没有恢复原片的三维工程或原始关键帧。进步来自扩大取样范围与改变观察问题。

## 2. 原片给出的三种有效关系

### 匹配的硬切

重新观察到：5.333331 秒仍为 WITH，5.416664 秒已切到产品背面。显示视频区域约为 x=16–896，文字约占 x=44–866，产品约占 x=50–860。两者左右边界、中央重心和银色视觉面积接近。

因此，“有硬切”并不能解释生硬。上一版把满幅 WITH 切成短小、偏暗的模块，造成了额外的视觉跳变。修订版扩大了产品投影尺寸与银色背面面积，并让切入后的旋转继续发展。

### 保留旧元素的重新排版

原片 AN AI 保留在上方，POWERHOUSE 加入下方；ONE、产品、MORE、TIME 也不断重新分配空间。新信息出现时，观众仍认得刚才的对象。

修订版开头保留 FROM / SRT，再扩展出 TO / STORY。结尾三个动词共用连续移动的文字序列，避免每个词各自起步、左右方向反复重置。

### 动作和含义的承接

原片 RENDER 后接线框逐渐成为实体的过程，蓝紫金属材质也得到延续。上一版直接切成独立白字 IN，丢失了这个关系。

修订版让 RENDER 留在上方，IN / 4K 接入；4K 从线框变为金属实体，再缩成下一段产品画面中的标识。同一个可识别元素贯穿几个阶段。

这些是依据原片关系为 H3Loom 编排的适配，不声称原片中存在相同文案和完全相同的连接。

## 3. 代码与节奏的具体纠偏

| 之前的处理 | 本次处理 | 对观感的作用 |
| --- | --- | --- |
| 大部分时间只显示一个镜头组 | `composeConnected` 允许前后元素在交接区间同时存在 | 旧对象能参与下一镜，避免每次清空重开 |
| 每个关键词独立入场并停稳 | 以共享排版和共用移动路径安排多个词 | 速度变化形成连续句子，而非多个独立标题卡 |
| 只调起点、终点和总时长 | 分别安排主要位移、微小余势和阅读停留 | 保留快节奏，同时给眼睛确认新构图的时间 |
| 只看文字表面有无动态 | 分开控制版式、产品运动和反射的时间 | 文字可停稳阅读，产品或光仍自然继续 |
| 音效主要跟镜头标记走 | 重音重新对齐主要位移和交接时刻 | 声画服务同一个动作 |

参考中部分快速重排的主要位移集中在约 42–83 毫秒，随后有较长的微小收敛。这是特定段落的观察与拟合依据，不应变成所有动画的固定时长。并非所有动作都需要弹性、反弹、预备动作或淡化；是否采用，取决于参考和内容。

## 4. 检查方式也发生了变化

- 先用连续参考样本说明交接关系，再决定代码结构。
- 检查相邻镜头的组合，既看运动中的画面，也看正常速度下的节奏；漂亮的静帧不代表衔接成立。
- 保留前一版视频，在同一时间点切换版本比较。
- 用实际新帧发现并修复了 H3/LOOM 离场时与 RENDER 相撞的问题。
- 新复合场景在 16 个交接相关时刻、5 种远跳来源下做了 80 次返回检查，像素一致；完整视频解码和播放也通过。

技术检查负责排除状态残留、错误帧和播放故障。审美认可来自对实际成片的判断，不能由“脚本无报错”或子 Agent 自报完成代替。

子 Agent 分工补足了参考观察、材质实现和渲染验证；主 Agent 仍需对整片的共同排版、节奏和跨镜头关系负责。

## 5. 下次可复用的最小工作法

1. **先拆一段相邻镜头。** 连续观察交接前后，记录对象、构图、方向、速度与明暗关系；分清观察到的事实和拟合选择。
2. **先写交接说明。** 简单写明“保留什么、改变什么、下一镜接住什么”；若是硬切，写出它匹配的视觉关系。
3. **做连续短样。** 选择包含两三次交接的片段，而非只展示一个好看的镜头。用正常速度与慢速分别检查节奏和过程。
4. **再扩成整片。** 把有效的关系写成可重复调用的动作与布局参数，减少上下文变长后的临场猜测。
5. **固定认可版本。** 保存视频、源码、参考证据和检查记录。后续调整从这个基准比较，避免无意退回已否定的处理。

本次有效的核心：把前镜的结束状态与后镜的开始状态作为同一个设计问题来解决。
